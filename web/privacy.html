Privasi & lisensi

Kamera di perangkat Anda

Kamera hanya diminta setelah Anda menekan Aktifkan kamera atau Gunakan kontrol tombol. Mikrofon tidak diminta. Pemrosesan video, wajah, dan tangan berjalan di browser. Video langsung dan landmark tidak dikirim ke cloud; hanya hasil foto akhir yang dapat dikirim setelah persetujuan.

Akun dan persetujuan cloud

Kamera, seluruh mode, pengambilan foto, galeri lokal, dan Print dapat digunakan tanpa login. Tombol Unduh PNG meminta login pada dialog di studio. Foto tamu tetap di perangkat dan dipindahkan ke cache akun setelah login eksplisit. Login tidak otomatis mengirim foto tamu ke cloud. Hanya akun pemilik dapat membuka salinan cloud miliknya di perangkat lain. Pengelola EGZ (EGYYFZA) dapat melihat foto yang Anda setujui untuk arsip studio melalui akses admin dengan autentikasi dua langkah. Tidak ada galeri publik.

Penyimpanan cloud dan arsip admin memerlukan persetujuan yang awalnya nonaktif. Tanpa persetujuan, foto tetap lokal. Persetujuan tidak mencakup publikasi atau pelatihan model. Mengaktifkannya mengizinkan pengiriman foto baru, tanpa mengunggah foto lama otomatis. Untuk menyimpan foto lama atau foto tamu yang sudah dipindahkan ke akun, aktifkan persetujuan lalu pilih Simpan foto ini ke cloud pada foto yang dimaksud. Anda dapat mencabut persetujuan di dialog Akun.

Foto PNG yang lebih besar dari batas unggahan 3 MB diperkecil khusus untuk salinan cloud dengan mempertahankan proporsinya. Foto asli pada galeri lokal dan unduhan lokal tetap utuh; unduhan dari galeri cloud mengikuti salinan cloud yang mungkin lebih kecil.

Semua salinan cloud pengguna dan admin memiliki masa simpan 30 hari sejak unggahan pertama berhasil. Membuka atau mengunduh foto tidak memperpanjang masa simpan. Akses dihentikan ketika kedaluwarsa dan foto dihapus otomatis. Foto yang telah kedaluwarsa tidak otomatis diunggah ulang dari cache lokal. Tombol Hapus cloud menghapus salinan cloud untuk pengguna dan admin; foto lokal serta berkas unduhan tetap Anda kelola sendiri.

Foto lokal dan cetakan

Hasil disimpan di browser dengan batas pengambilan 12 foto/strip dan 40 MiB. Penggabungan foto tamu ke akun mempertahankan foto yang sudah ada; jika jumlah gabungan melampaui batas, hapus sebagian sebelum mengambil foto baru. Cache akun dipisahkan per UID dan dibersihkan saat keluar atau berganti akun. Foto tamu belum terikat identitas; orang yang memakai profil browser sama dapat membukanya. Hapus foto tamu setelah selesai pada perangkat bersama. Foto demo lama berada di ruang terpisah dan tidak otomatis dimasukkan ke akun.

Jika penyimpanan gagal, penuh, atau diblokir, hasil ditahan sementara di memori tab dan diberi keterangan. Hapus lokal hanya menghapus salinan browser. Penyimpanan browser bukan cadangan permanen: menghapus data situs, mode privat, atau pembersihan browser dapat menghilangkannya. Foto yang belum diunggah tidak tersedia di perangkat lain.

Unduh PNG meminta akun aktif dan menyimpan berkas di perangkat. Jika layanan akun belum tersedia, foto tetap dapat dipakai di studio dan dicetak; pengunduhan menunggu login berhasil. Salinan lokal dan berkas unduhan tidak dihapus oleh retensi cloud. Orang yang menguasai perangkat/profil browser tetap dapat mengakses data lokal. Login untuk unduh merupakan alur aplikasi, bukan perlindungan dari tangkapan layar atau akses fisik ke perangkat.

Sebelum login, galeri dan Print menampilkan pratinjau ber-watermark dengan sisi terpanjang maksimal 960 piksel. Setelah login, hasil asli tersedia untuk pratinjau, Print, dan Unduh PNG. Foto asli tetap disimpan lokal untuk pemulihan; watermark tidak mencegah Inspect, screenshot, atau akses oleh pemilik profil browser. Print membuka dialog cetak browser untuk foto pilihan Anda. Anda menentukan printer, kertas, dan skala. Aplikasi tidak dapat memastikan apakah benar-benar tercetak. Dialog cetak dapat menggunakan layanan printer atau penyimpanan PDF yang Anda pilih.

Perangkat

Studio mendukung kontrol sentuh, mouse, dan keyboard. Laptop atau desktop direkomendasikan untuk ruang gerak kedua tangan. Perangkat dengan layar kecil, input sentuh, atau kemampuan terbatas memakai preferensi kamera dan pelacakan yang lebih ringan. Resolusi aktual mengikuti kemampuan kamera dan browser. Akses kamera memerlukan HTTPS atau localhost serta izin Anda.

Model dan penyedia hosting

Model dan runtime MediaPipe dimuat dari situs ini. Berkas berasal dari Google dan memiliki ketentuan terpisah. Browser berkomunikasi dengan layanan akun pada situs ini; backend menggunakan Supabase untuk autentikasi, metadata, dan penyimpanan privat di region Singapore. Penyedia hosting tetap dapat mencatat permintaan situs dan informasi koneksi menurut kebijakan layanannya. Cookie sesi dipakai untuk login; token akses tidak disimpan di penyimpanan JavaScript browser.

Open source

Kode proyek menggunakan lisensi MIT. Lihat atribusi pihak ketiga dan Apache-2.0. Lisensi kode tidak memberikan hak atas foto pengguna atau merek pihak ketiga.
