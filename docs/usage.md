# Using EGZ studio

Open [the studio](https://egz-gesture-studio.netlify.app), choose **Aktifkan kamera**,
and allow camera access. Keep your hands visible in even lighting. Follow the
calibration prompt, or press **M** to choose a mode with conventional controls.
Each mode has a short tutorial; replay it from the tutorial menu or switch off
automatic tutorials.

| Mode | Gesture |
| :-- | :-- |
| Hand effects | Two fingers blur the full image. Two upright L shapes define a blur area; opposite L directions create mosaic; two inverted L shapes rotate the area. |
| Painting | Pinch thumb and index finger to draw. An open palm or relaxed fist erases locally. Select a shape and use two pinches to position it. |
| Photobooth | Hold a fist briefly to start a three-shot sequence. Open your hand before starting another session. The completed strip opens automatically. |
| Memes | Combine expressions and gestures: raised index + smile, finger near mouth + smile, surprised face + hands near chest, or tongue + smile. |

Use the side **Alat** icon for tools. Close the panel with **X** for an unobstructed
view. **Preview Photo** opens your local gallery; choose **Unduh PNG** or **Print**.
Printing opens your browser's print dialog.

## Keyboard

| Key | Action |
| :-- | :-- |
| `M` | Open mode selection |
| `1`–`4` | Switch modes |
| `S` | Save a photo |
| `Space` | Start Photobooth |
| `P` | Print |
| `X` | Stop the camera |
| `R` | Retry a failed save |
| `Escape` | Cancel the current session |

In a focused Painting canvas, arrow keys move the pen/shape, Space toggles the
pen, Shift + arrows resizes a shape, Enter places it, and Escape cancels it.

## Your photos

New photos stay in the current browser profile. The local gallery holds up to
12 photos/strips and 40 MiB. Download the originals you want to keep: clearing
browser storage, changing devices, or using private browsing can remove access.
If storage is full, keep the page open and download the temporary result.
People using the same browser profile can see its local gallery.

Tracking depends on lighting, hand visibility and camera quality. If a gesture
is hard to recognize, use the mouse, touch or keyboard controls. Physical device
performance varies; laptops and desktops are the primary target.
